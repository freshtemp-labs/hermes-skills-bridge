## xurl 配置步骤（需要老板手动完成）

1. 打开 https://developer.x.com/en/portal/dashboard
2. 创建或打开一个 App
3. 设置 Redirect URI 为 `http://localhost:8080/callback`
4. 复制 Client ID 和 Client Secret
5. 在终端运行：
   ```bash
   xurl auth apps add my-app --client-id YOUR_CLIENT_ID --client-secret YOUR_CLIENT_SECRET
   ```
6. 认证：
   ```bash
   xurl auth oauth2 --app my-app
   ```
7. 设置默认 App：
   ```bash
   xurl auth default my-app
   ```
8. 验证：
   ```bash
   xurl auth status
   xurl whoami
   ```
